# وِرد — مدير حلقات التحفيظ (أوفلاين)

## بناء الـ APK (من غير تثبيت أي شيء على جهازك)
1. أنشئ مستودع جديد على GitHub (خاص Private مناسب).
2. ارفع محتويات هذا المجلد كما هي (بما فيها مجلد `.github`).
3. افتح تبويب **Actions** ← سيبدأ «Build APK» تلقائياً (أو اضغط Run workflow).
4. بعد ~5-8 دقائق افتح التشغيل الناجح ← **Artifacts** ← نزّل `werd-apk` وفك الضغط.
5. انقل `app-release.apk` لموبايلك وثبّته (فعّل «التثبيت من مصادر غير معروفة»).

إذا فشل البناء: افتح الخطوة الحمراء وأرسل لي نص الخطأ وأصلحه.

## ملاحظات
- البيانات في قاعدة SQLite محلية على الجهاز، ولا يحتاج التطبيق إنترنت.
- النسخ الاحتياطي: الإعدادات (أيقونة الترس في الرئيسية) ← تصدير نسخة ← احفظها خارج التطبيق.
- الاستعادة تستبدل البيانات الحالية بالكامل (مع ملف أمان تلقائي داخل التطبيق).
